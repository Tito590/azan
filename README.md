# Kamanika Argopuro AR v4

## Alur
QR -> buka halaman -> browser meminta izin kamera -> kamera belakang aktif -> petani langsung muncul -> frame 1-5 berulang untuk efek tangan melambai -> balloon text muncul di atas topi -> pouch besar di kanan bawah -> tombol BELI ROASTBEAN.

## Perubahan v4
- Frame kotak/scan frame dihilangkan.
- Suara/TTS dihilangkan seluruhnya.
- Balloon diposisikan di tengah atas dengan ekor tepat mengarah ke topi petani.
- Pouch diperbesar.
- Tombol bawah menjadi BELI ROASTBEAN.
- Lima frame petani berganti otomatis.
- Semua asset petani dan pouch mengambil URL raw GitHub yang diberikan.

## Instalasi
Copy `index.html`, `style.css`, `app.js`, dan `config.js` ke root repository GitHub Pages Anda.

QR yang mengarah ke `https://tito590.github.io/azan/` akan tetap bisa digunakan jika file-file ini ditempatkan sebagai halaman utama repository tersebut.

Kamera membutuhkan HTTPS. GitHub Pages sudah HTTPS.

# Kamanika Argopuro 360° — Simple Mode

Versi ini sengaja TIDAK menggunakan kamera, AR permission, WebGL, Three.js, Canvas, atau sensor HP.

Alur:
QR → halaman langsung terbuka → kebun 360° langsung tampil → user geser layar ke kiri/kanan.

Fitur:
- Panorama equirectangular 360°
- Satu lebar panorama = 360°
- Panorama bergerak halus menggunakan requestAnimationFrame
- Drag/touch sebagai kontrol utama
- Petani 5 frame melambai
- Pouch Argopuro
- Balloon text
- Indikator derajat dan arah
- Tombol BELI ROASTBEAN
- Tanpa kamera
- Tanpa suara
- Tidak ada permission

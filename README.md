# Kamanika Argopuro 360° — Simple Smooth v9

Mode ini sengaja dibuat sesederhana mungkin.

Tidak ada:
- kamera
- permission
- gyroscope
- AR
- WebGL
- Three.js
- Canvas

Alur:
QR → halaman langsung terbuka → petani langsung terlihat → user membaca instruksi → user swipe kiri/kanan untuk melihat kebun.

Kontrol:
- Swipe kiri/kanan dengan jari.
- Gerakan panorama dihaluskan menggunakan requestAnimationFrame + interpolation.
- Tidak ada event sensor.

Fitur tetap:
- Kebun panorama
- Petani 5 frame melambai
- Balloon text
- Pouch Argopuro
- Tombol BELI ROASTBEAN
- Indikator arah
